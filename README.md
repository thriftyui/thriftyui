# ThriftyUI

A React UI kit: components on Radix Primitives and Radix Colors, styled
with Tailwind CSS 4. The package is `thriftyui` (0.1.0); its docs are at
https://www.thriftyui.com, and for language models at
https://www.thriftyui.com/llms.txt.

- `kit/` -- the kit. How an app uses it: `kit/README.md`.
- `starters/` -- one small app per layout, and a Chrome extension.
- `templates/terminal-and-files/` -- a desktop app template (Tauri).
- `demo/` -- an app using the built kit.

`npm install`, then `npm run build` and `npm test`.
